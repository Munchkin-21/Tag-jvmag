# Nomenclature des tags — JVMag (v3.4, finale après pilote de 50 articles)

**But unique des tags :** nourrir la recherche et la reco de l'app via un maillage dense.
Un tag vaut par les liens qu'il crée. Cible : **8–10 tags / article** (moins pour les news courtes,
agendas et programmes — c'est normal).
**Catégories WordPress : on n'y touche pas.** Tags uniquement.

---

## Structure d'un article (checklist auteur)

Licence/sujet → Studio(s) + éditeur → Genre(s) → Plateforme(s)/Composant(s) → Thèmes/univers →
Événement → (Pays si central). L'ordre n'est pas stocké, c'est un garde-fou de couverture.

---

## §1 — Licences / sujets — OUVERT
- **Franchise sans numéro ni adjectif.** Red Dead Redemption 2 → `Red Dead Redemption` ;
  Final Fantasy VII Revelation → `Final Fantasy` ; Alien Isolation 2 → `Alien`.
  → La différenciation interne se fait par les **genres** (`Final Fantasy` + `MMO` = FF XIV ;
  `Final Fantasy` + `Action-RPG` = le remake FF7). Pas de double franchise+sous-saga.
  → Bonus cross-media : `Alien` relie le jeu ET le film ET la série.
- **Œuvre citée en comparaison ≠ tag** (« à la sauce God of War » → pas de tag).
- **Personne = sujet → taguée** (interview, portrait, nécro, news de casting qui porte sur elle).
- **Rôle central tagué, mention anecdotique non.**
- **Personne réelle en vedette taguée si elle est le hook** (Tupac & Snoop Dogg dans un jeu).

## §2 — Studios / éditeurs / marques — OUVERT
- Règle « acteur le plus **utile** » : God of War → Santa Monica Studio.
- **Studio dev toujours + éditeur first-party majeur** s'il est une marque-source suivie
  (Xbox Game Studios, PlayStation Studios, Nintendo, SEGA, Square Enix…). NB : le tag plateforme
  (`Xbox`) ≠ l'éditeur (`Xbox Game Studios`) — l'un = dispo, l'autre = curation first-party.
- **Marque/studio obscur : tagué s'il EST le sujet** (Ventiva) ; ignoré s'il est secondaire.
- Pas de studio connu mentionné → tague les **autres jeux du même créateur** (pont d'auteur).
- **Pedigree non tagué** : anciens employeurs / équipe d'origine ≠ tag (Bioware/ND/343 ;
  « l'équipe de Yakuza »).
- **Marque selon ce que dit l'article**, pas selon ce qu'elle est : sponsor cité au titre mais
  absent du corps → non tagué.

## §3 — Genres — FERMÉ
Action · Aventure · Action-aventure · RPG · JRPG · Action-RPG · FPS · TPS · Plateforme ·
Metroidvania · Roguelike · Souls-like · Infiltration · Stratégie · Tactique · Simulation ·
Gestion · Sport · Course · Combat · Réflexion · Hack'n'slash · Beat'em up · Shoot'em up ·
Survie · MMO · Battle royale · Party game · Rythme · Narratif · Deckbuilder · Point & click ·
Tower defense · Idle · Cosy
*Film/série :* Horreur · Comédie · Drame · Thriller · Science-fiction · Fantastique · Aventure ·
Action · Policier · Documentaire · Biopic (+ `Animation` si pas d'acteurs réels).

## §4 — Plateformes & matériel — FERMÉ
**On liste chaque plateforme réelle.** Pas de collectif « Console ». Pas de numéro.
**Jeux :** PC · PlayStation · Xbox · Nintendo Switch · Mobile · Steam Deck · VR · Cloud gaming · Rétro
**Films/séries :** Netflix · Disney+ · Prime Video · Apple TV+ · HBO Max · Paramount+ · Crunchyroll · Canal+
**Composants & matériel :** Carte mère · Processeur · Carte graphique · RAM · SSD · Alimentation ·
Boîtier · Refroidissement · Écran · Clavier · Souris · Casque audio · Matériel PC · Périphérique ·
Smartphone · Réseau · AR

## §5 — Thèmes & univers — semi-fermée (le moteur du maillage)
**Admission (3 tests) :** factuel + définissant + **revendiqué par le lecteur** (« j'aime les ___ »).
**Univers / cadre :** Fantasy · Science-fiction · Cyberpunk · Post-apocalyptique · Médiéval ·
Mythologie · Espace · Far West · Pirates · Guerre · WW1 · WW2 · Guerre froide · Zombies ·
Dinosaures · Super-héros · Horreur · Enquête · Steampunk · Lovecraftien · Aviation · Maritime ·
IA · Robot · Années 80
**Mécaniques revendiquées :** Solo · Multijoueur · Coopératif · Compétitif · En ligne · Local ·
Cross-play · Monde ouvert
**Qualificatifs permanents :** Indé · Gratuit · Remake · Remaster · Rétro · Esport · Animation
**Métiers / sujets :** Doublage · Cinéma
**Rubriques éditoriales (suivies par le lecteur) :** Carnet noir · Montage PC

**EXCLUS :**
- **Ton / ambiance** (Sombre, Mélancolique, Stressant, Épique) → interprétatif.
- **Statut / format** (Démo, Bande-annonce, Teaser, Accès anticipé, AAA, **Reboot**, **Exclusivité**)
  → transitoire/subjectif. *(Remaster/Remake restent : nature permanente.)*
- **Techniques de production & styles graphiques** (Procédural, Ray tracing, moteurs, **Pixel art**,
  voxel, self-shading, cel-shading) → invisibles / non revendiqués.

## §5bis — Automobile — sujet RÉEL uniquement
`Voiture` (générique) · `Voiture hybride` · `Voiture électrique`. Chaque voiture = `Voiture` +
sa motorisation. **Les jeux de voiture/course se taguent via le genre `Course`**, jamais `Voiture`.

## §6 — Événements — FERMÉ
Evergreen (l'année vit dans la date). Un événement terminé garde son tag.
**Jeux vidéo :** Summer Game Fest · Gamescom · Nintendo Direct · State of Play · Xbox Showcase ·
The Game Awards · Paris Games Week · Polymanga · Red Bull Gamerations
**Tech / auto :** CES · Computex · WWDC · Goodwood Festival of Speed
**Ciné / pop culture :** Festival de Cannes · Oscars

## §7 — Local suisse — FERMÉ (un seul tag)
**`Suisse`** dès qu'il y a un **angle suisse réel** (sujet local, événement en Suisse,
lancement/prix spécifiquement suisse) — pas pour une simple dispo mondiale. **Pas de tags de ville.**

## §8 — Pays — OUVERT, barrière stricte
Un pays n'est tagué **que s'il est l'acteur central** (« la Chine légifère », « ventes au Japon »),
jamais pour une mention incidente.

## Règles transversales
- **Tag large vs catégorie** : on ne tague pas le médium si la catégorie le dit déjà
  (pas de `Série` en News Séries). Exception `Cinéma` (thème transversal salle/industrie/festival —
  pas sur chaque film précis).
- **Listes = pas de tags** : nominés, jeux-épreuves, programmes, line-up → on ne tague que le sujet.
- **SF spatial** → `Science-fiction` + `Espace` quand l'espace est central.
- **Pas de tag `Adaptation`** : le jeu et son film partagent simplement la franchise.
- **Facette absente → incertitudes** : si une facette clé manque (plateforme non citée), le pipeline
  le signale pour complément humain — il n'invente pas.
- **Nommage** : facettes fermées = on pioche ; une forme canonique unique (casse/accent/pluriel) ;
  singulier par défaut ; un tag = une entité/concept.

## Gouvernance & étape auto (verrou anti-dérive)
**Liste maîtresse = les tags actuels du site, lus via l'API REST à chaque lot.** Zéro entretien.
1. On injecte la liste existante dans le prompt.
2. Facettes **fermées** : l'IA pioche, n'invente **jamais**.
3. Facettes **ouvertes** : réutiliser la forme **exacte** ; vérifier les variantes avant de proposer.
4. **Un nouveau tag n'est jamais écrit direct** : il sort dans `nouveaux_tags`, validé avant.

### Squelette de prompt (étape auto)
```
Tu tagues un article de JVMag (jeux vidéo / tech / pop culture, Suisse romande).
But : maillage pour la recherche et la reco. Tu reçois le TEXTE INTÉGRAL, la CATÉGORIE,
et la LISTE DES TAGS EXISTANTS du site.

1. 8 à 10 tags : licence (franchise sans numéro/adjectif), studio dev + éditeur majeur,
   genre(s), plateforme(s)/composant(s), thèmes/univers, événement, pays (si central).
2. FERMÉ (genres, plateformes/matériel, événements, univers/mécaniques, local) : choisis
   UNIQUEMENT dans les listes fournies. N'invente JAMAIS. Rien ne colle → rien.
3. OUVERT (licences, studios, pays) : réutilise la forme EXACTE existante ; sinon → "nouveaux_tags".
4. Vérifie qu'aucune variante (casse/accent/pluriel/tiret) n'existe déjà.
5. Exclus : comparaison ; mention anecdotique ; ton/ambiance ; statut/format (démo, bande-annonce,
   accès anticipé, AAA, reboot, exclusivité) ; techniques de prod & styles graphiques ; pedigree ;
   sponsor absent du corps.
6. Personne = sujet ou vedette-hook → tague. Liste d'items → ne tague pas.
7. Médium déjà dans la catégorie → ne le tague pas (sauf Cinéma). Voiture = sujet réel, pas les jeux (→ Course).
8. Suisse = angle suisse réel. Facette clé manquante → "incertitudes".

Sortie JSON : { "tags": [...], "nouveaux_tags": [...], "incertitudes": [...] }
```
