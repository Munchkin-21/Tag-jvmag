## Journal des décisions ouvertes (à surveiller)
- **Mediawan** : gardé, à réévaluer s'il n'est pas réutilisé.
- **Unitree** : gardé comme le plus connu des fabricants de robots.
- **Montage PC** : rubrique provisoire, on juge à l'usage.
- **Labels ciné vs distributeurs** : labels créatifs reconnaissables tagués (A24, Disney, Pixar…) — à confirmer.
- **Xbox Game Studios / éditeurs first-party** : tagués comme axe « curation » distinct de la plateforme — réversible si bruit.

## Deltas de nomenclature à reporter dans le doc (→ v3.4)
- **Pixel art RETIRÉ** + tout style graphique banni (voxel, self-shading…) → EXCLUS §5.
- **Années 80 AJOUTÉ** (univers).
- **Pedigree non tagué** : anciens employeurs / équipe d'origine ≠ tag (Bioware/ND/343 pour EXODUS ; Yakuza pour Stranger Than Heaven).
- **Exception plateforme-sujet** : plateforme non utilisée non taguée, SAUF si elle est le sujet (Arizona → VR).
- **Facette absente → incertitudes** : signaler toute facette clé manquante (plateformes non citées).
- **AUTO → 3 tags** : Voiture / Voiture hybride / Voiture électrique ; chaque voiture = Voiture + motorisation.
- **`Voiture` = sujet réel uniquement** : les jeux de course se taguent via `Course`, pas `Voiture`.
- **`Réseau` AJOUTÉ** (§4).
- **Événements tech/auto AJOUTÉS** : Computex, WWDC, Goodwood Festival of Speed.
- **Marque obscure = sujet → taguée** (Ventiva) ; on n'ignore que les marques SECONDAIRES obscures.
- **Règle `Suisse` affinée** : angle suisse réel, pas dispo mondiale.
- **Noms de modèles one-shot non tagués** ; exception gammes majeures récurrentes.
- **`Cinéma` réservé** aux sujets salle/industrie/box-office/festival.
- **Personne taguée = tête d'affiche (réal/acteur/vedette réelle) qui est l'argument de la news** (Tupac, Snoop Dogg inclus).
- **Pas de tag `Adaptation`** ; jeu et film partagent la franchise.
- **SF spatial → `Science-fiction` + `Espace`** quand l'espace est central.
- **LICENCE = franchise sans numéro ni adjectif** (Final Fantasy, Alien) ; différenciation interne par les genres ; pas de double franchise+sous-saga.
- **Éditeur + dev** : studio dev toujours + éditeur first-party majeur tagué aussi.
- **Pas de tag `Reboot` ni `Exclusivité`** (statuts, comme AAA).
